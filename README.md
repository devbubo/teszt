# Bitcoin figyelő

Egyszerű, telefonon is jól használható bitcoin-oldal.

**Élő oldal:** https://devbubo.github.io/teszt/

## Mit tud?

- **Élő ár** forintban és dollárban, 24 órás változással, percenkénti frissítéssel.
- **Grafikon** 7 napra, 30 napra, 1 évre és a teljes időszakra. Ujjal végighúzva látod az adott napi árat.
- **„Mi lett volna, ha…” kalkulátor:** megadsz egy összeget és egy dátumot, és kiszámolja, mennyit érne ma. Forintnál az akkori dollár–forint árfolyammal számol.
- **Satoshi-átváltó:** 1000 Ft hány satoshi.
- **Halving-visszaszámláló:** hány blokk és nagyjából hány nap van a következő felezésig.

## Adatforrások

CoinGecko (élő ár, grafikon), CryptoCompare / Binance (régi árak), mempool.space (blokkszám), Európai Központi Bank a Frankfurter API-n keresztül (forintárfolyam).

Nem befektetési tanács.
