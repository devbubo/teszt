# teszt

Az első teszt projektem a GitHubon.

## Mi van benne?

- `index.html` – egy egyszerű weboldal egy gombbal, ami számolja, hányszor nyomtad meg.
- `README.md` – ez a leírás. A GitHub automatikusan megjeleníti a repó főoldalán.

## Hogyan nézhetem meg?

Töltsd le az `index.html` fájlt, és nyisd meg böngészőben.
